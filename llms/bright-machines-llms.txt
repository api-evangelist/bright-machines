# Bright Machines

> Bright Machines is a San Francisco software-defined manufacturing company (founded 2018 by Amar Hanspal and Lior Susan) building a full-stack intelligent automation platform for electronics and AI-infrastructure assembly. Its Microfactory combines modular Bright Robotic Cells with Brightware — a platform operating system that orchestrates hardware, runs a machine-vision "Smart Skills" perception stack, and delivers manufacturing-execution services for work orders, material management and real-time production KPIs. Bright Data unifies component, process and enterprise-system data through secure APIs and auditable data flows; Bright Designer turns product CAD into assembly-ready digital twins on NVIDIA Omniverse and Microsoft Azure.

## API surface

Bright Machines publishes **no public API**. There is no developer portal, no API reference,
no OpenAPI/AsyncAPI/GraphQL contract, no SDKs on any public package registry, no CLI,
no hosted MCP server and no A2A agent card. The platform's APIs (Brightware/Bright Data
integrations into MES, ERP and Azure) are delivered to customers under commercial
engagement rather than as a self-serve public product. Probed 2026-08-01 — see
`well-known/bright-machines-well-known.yml` for the full negative-result record.
